# Inter

Inter is the proposed UI family in the Mi Ruta design system, edition 02; it was not identified as the original app's font. Bundled static weights: Regular 400, Medium 500, SemiBold 600, Bold 700. No runtime network requests.

Source: https://github.com/google/fonts/tree/main/ofl/inter. Static instances from the Inter variable font at optical size 14, with unique PostScript names. SIL Open Font License in OFL.txt. The font inside the raster logo remains untouched.
